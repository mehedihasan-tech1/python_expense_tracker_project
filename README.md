A simple Python-based Expense Tracker that allows user to record, manage, and track their daily expenses.

***Features***
--> Store expense name, category, and amount
--> Display recorded expenses
--> Organise expenses by category
--> Object-oriented programming using Python classes

***Python learning goals***
--> Python function
--> __init__ method
--> __repr__ method
--> File handling
--> CSV data handling
--> Basic project structure
